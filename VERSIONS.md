Editions (licence-controlled, one installer) — PREPARED BUT NOT ACTIVE (AV.LICENSING = false in licence.js until the user decides the licensing scheme)
- No key → OsemCM 1D (unregistered). 1D key → OsemCM 1D. 1D-2D key → OsemCM 1D-2D (2D Flood ribbon tab, 2D Options, Create Meshes, 1D-2D run, flood maps).
- Keys: `license-tools/keygen.js --edition 1D|2D --name "Licensee" [--expiry YYYY-MM-DD] [--serial S]`; signed with `license-tools/private_key.pem` (NOT in git, copy kept in releases/license). The public key is in app/main.js.

Rules
- 1D fixes requested "based on OsemCMV1.0" are made on branch `v1` (versions 1.23.x) and can be merged into `main`.
- 2D work is done on `main` only.
- Every installer that is sent out gets a tag (`v1.23.x` / `v2.0.x`) and a line in CHANGELOG below.

## CHANGELOG
- v1.23.0 — V1.0 baseline (last 1D-only build).
- v2.0.0 — First V2.0 build: 2D Flood module (Options → 2D Flood, Create Meshes, 1D-2D run to .finp/.frpt/.fout, Meshes layer coloured by depth / max depth / time ponded / time to recede / elevation, cell properties + graph, mesh shapefile export, Avaris DS .ini [2D] import). Mesh rules reproduce Avaris DS (verified on demo3: 1497 cells, 2852 surface links, 551 manhole couplings, 15 water-front outfalls, identical cell elevations and link lengths). Fix: Avaris .ini [Reference] coordinate system index.
- v2.0.1 — Licence editions (1D / 1D-2D) with offline signed keys; Help → Register activates; 2D functions moved to their own "2D Flood" ribbon tab (locked without a 1D-2D key) and a separate 2D Options dialog. Split cursors: square on/inside the subcatchment, triangle on a conduit, normal pointer elsewhere. New Register / User Guide icons. Profile table "Link" caption no longer clipped.
- v2.0.2 — Licensing switched off (all functions available, simple Register form). No separate 2D ribbon tab: Create Meshes is back in Simulation and the 2D settings are the "2D Flood" tab of Simulation Options. The 1D / 2D split is recorded in docs/FEATURES-1D-2D.md (all 2D entry points go through AV.has2D).
- v2.0.3 — Checkboxes left-aligned in all forms; ✎ buttons open the referenced time series / curve (rain gages, climatology, land use, inflows, property grid); Copy / Paste (Excel) in Time Series and Curve editors; hyetograph start date/time (default model start) with computed end, dated time series; 2D Meshes layer in the network drawing order (drag); Meshes style in the Symbology pane (variable, ranges, ramps, transparency, outlines); 1D-2D input written without engine warnings 02/10 (same results); graph follows clicked 2D cells, titled "2D Cell".
- v2.0.4 — 2D Flood tab: "Tag all nodes Link2D"; 2D Meshes attribute table (sort, click to zoom, copy to Excel); Time Step pane shows a selected 2D cell; cell properties follow the time slider; rain units IN/MM selectable for time-series gages (converted on run, stored as ;;@OSEM RAINUNITS); rainfall file "…" switches the gage to FILE; "Capacity" labels without d/D; Play after Quit reloads the last results file.
- v2.0.5 — Play mode: Play toggles play mode (2nd click = Quit); Quit keeps results loaded; dynamic-result themes (▶) only in play mode, other themes only outside; "Results at / Simulation Maxima" cards only in play mode; Time Step tool removed. 2D Meshes in the standard Attribute Table (select, select by attribute, invert, zoom, copy/paste, edit elevation & roughness, calculator, statistics, colour map); multi-cell selection (click, Ctrl, box). Mesh only takes clicks inside subcatchments when drawn above them. Cell properties: Statistic Results + play-mode "Results at" depth card; mesh variable for play / non-play. LID schematic sketches. Report banner removed. Clause editor: empty clause + OK = no change. 2D Run Units default MODEL (as Avaris: keep model flow units), options SI / CONVERT; 2D routing step blank = model step.
- v2.0.6 — Mesh: all variables (incl. ground elevation, water surface) shown by editable ranges; depth & water surface (current time) only in play mode (blue "Results at" card with both; selecting them outside play mode is refused with a message); static / statistic variables always. Flow units switch in the status bar (and Simulation Options): choose to convert all model values (US <-> SI or between flow units, with undo) or keep the values.
- v2.0.7 — 2D "Run Units" replaced by "Mesh Units" (MODEL / CONVERT); the SI run switch is removed (switch the flow units with "Keep values" instead). CONVERT now converts cell lengths, widths and DEM / water-front elevations from map units to model units.
- v2.0.8 — Every Run asks for a simulation name; results are kept in <model>_Results/<name>.{inp,rpt,out,json} (same name = replaced; no more growing .run.inp files). Left dock tabs Designer (Parameter View + Layer View) / Database (base model + simulation results: double-click opens a result or the base model only; rename, delete, report, compare). Number of Threads: "Detect & Recommend" (cores, maximum = logical − 1, model-based recommendation). Scenarios run in parallel, one engine process each (1 thread each), with per-scenario progress and Stop All.
- v2.0.9 — Ribbon redesigned after ArcGIS Pro (icons unchanged): white card panel, 34 px large buttons with two-line labels, 3-row small-button stacks, dialog launchers, underlined tabs. Operation: Navigate (Pan, Zoom to All, zoom stack, Bookmarks ▾) / Selection (Select, Search, groups) / Edit / Display / Change Log. Tools: Connectivity / Network Geometry (incl. Orifice to Conduit, Measure) / Rainfall (Design Storm) / Spatial Reference / Utilities (Validate Model, Unit Converter). Simulation: Setup / Run / Results. New Design Storm dialog: method buttons, live hyetograph with cumulative curve, custom pattern table (% per interval or cumulative %), draw on the chart, paste from Excel, presets, normalize; invalid patterns (decreasing cumulative, negative rain) are marked and cannot be added; rain gage chooser; date / time pickers.
- v2.0.10 — Product renamed OsemCM → Avaris2 (window title, dialogs, installer Avaris2-Setup-x.exe, Avaris2.exe, new A² logo for app / exe / installer / shortcuts; settings, users and history stay in the existing user-data folder). Ribbon icons optically normalised (cropped to content, equal visual size on a 64 px canvas; tools/iconnorm). Create Group removed from the ribbon: "Groups" button opens the redesigned Manage Groups panel (group table with node / link / subcatchment counts; actions grouped Group / Show / Members incl. Create Group; buttons enabled only when they apply). Comparison is a large button.
- v2.0.11 — Time functions in theme / clause expressions (minutes, from all reported time steps, computed once in the background): dur, run, win (up to the current step) and totdur, maxrun, maxwin, first, peak (whole run); new fields crownElev, maxVolume, sysRain; fullFlow for more shapes. Insight Flags theme files (Avaris2_Insight_Flags_SI / _US.json, 12 flags + "worst over run" variants, levels Normal / Warning / High / Critical); Theme Load asks Add (on top) or Replace; range labels in the legend. New Report viewer: Overview (KPI cards, water balance bars, time steps, options, top lists), Continuity, Warnings, Insights (worst level + dur / run / win statistics of each flag that uses them, CSV), Convergence, sortable / filterable result tables, full text. Map: eye button (T) hides / shows theme and mesh colouring; Locator overview map (click / drag to move, wheel to zoom). Large ribbon icons 20 % smaller; new Assign Outlet icon.
- v2.0.12 — Report: cards / tables reflow to the window width (no more values outside the boxes). Colleague feedback: hi-res icon set (256 px originals, normalised), Clear Trace = clear icon, Measure = ruler, Assign Outlet original icon, dialog launchers removed, Bookmarks group with Create Bookmark / Manage Bookmarks side by side. Coordinate systems: WKT2 (PROJCRS), Hotine Oblique Mercator A/B (e.g. Michigan GeoRef), Michigan LCC scale factor; <model>.prj now has priority over the .ini [Reference]; unsupported / misplaced systems are reported; Map Coordinate System shows where the model centre lands (lat / lon, link to OpenStreetMap) and has Michigan presets. Large models: renderer heap limit raised to 4 GB; Help ▸ Diagnostics shows timings (read, parse, index, redraw, results, time step) and memory.
- v2.0.13 — Large-model map speed (level of detail): zoomed out, the network is shown from a whole-model overview bitmap (4096 px, rendered in tiles over several frames into a back buffer, nearest the screen first), so zooming / panning at that range takes ~10 ms instead of ~1 s on a 3-million-object model; content changes keep the old bitmap until the new one is ready; detailed drawing resumes when zoomed in (no upscaling blur). Theme styles computed once per object per frame and skipped for layers without an active theme; overview junctions drawn as dots; basemap tiles no longer trigger network redraws; Locator reuses the overview. Run icon 30 % smaller.
- v2.0.14 — Flag panel (Operation ▸ Flag, bell icon): 12 built-in flags + user flags; one flag per layer (nodes / links / subcatchments, each with None); editable parameter boxes in the algorithm text, units follow Flow Units (ft or m, converted when it changes); ▶ current step / Σ worst over run; colour dialog (colours only, Normal may be No fill, read-only conditions); New flag wizard with clause editor and parameter table; Edit / Delete user flags; Import / Export; settings saved in <model>.flags.json. While flags are shown all theme items are suspended; closing the panel restores them. Report Insights uses the flag parameters. Insight Flags theme sample files removed.
