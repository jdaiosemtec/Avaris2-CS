Climatology Editor

The Climatology Editor holds the climate data of the model: air temperature, evaporation, wind speed, the snowmelt settings, the areal depletion of snow cover and monthly adjustments of temperature, evaporation, rainfall and soil conductivity. Open it from Parameter View ▸ Climatology: each entry (Temperature, Evaporation, Wind Speed, Snow Melt, Areal Depletion, Adjustments) opens the same editor on that tab. The Climate File tab has no entry of its own; reach it from any of the other tabs.

Step by step

  1. Click an entry under Parameter View ▸ Climatology. The Climatology Editor opens on that tab.
  2. Switch between the tabs at the top as needed. All tabs are edited together.
  3. If Temperature, Evaporation or Wind Speed is to come from a climate file, choose the file on the Climate File tab first (button …).
  4. To use a time series (temperature or evaporation), pick it in the list. The ✎ button next to the list opens the Time Series Editor, so you can view, edit or create the series without leaving the dialog; the list is refreshed afterwards.
  5. Click OK. The editor checks that a climate file is chosen when a tab needs one and that the chosen time series are set; otherwise a message names the missing item and the dialog stays open. All changes are applied as one step that you can undo.
Note:

Units follow the flow units of the model: °F, in, in/day and mph for US flow units (CFS, GPM, MGD); °C, mm, mm/day and km/hr for SI flow units (CMS, LPS, MLD).

Rain Gage Editor

A rain gage supplies precipitation to the subcatchments that reference it, either from a time series in the model or from an external rainfall file. Open the Rain Gage Editor from Parameter View ▸ Hydrology ▸ Rain Gages. A single gage selected on the map can also be edited in the Properties pane.

Step by step

  1. Click Parameter View ▸ Hydrology ▸ Rain Gages. The list on the left shows all gages; the fields on the right belong to the selected one.
  2. To add a gage, click +. It gets a unique name (RG_1, RG_2 …), the first time series of the model, a time interval of 1:00 and the rain units of the project. A new gage is placed at the upper-left corner of the model extent; move it on the map later if needed.
  3. To copy a gage, select it and click ⧉. The copy is named name_copy.
  4. To delete a gage, select it and click −. A gage that is still used by subcatchments cannot be deleted: assign another gage to those subcatchments first.
  5. Choose the Data Source. For TIMESERIES pick the series; the ✎ button opens the Time Series Editor. For FILE click … next to File Name; choosing a file switches the data source to FILE.
  6. Click OK. Renaming a gage also updates the subcatchments and unit hydrograph groups that use it. The change can be undone.

Aquifer Editor

An aquifer describes the soil below a subcatchment as an upper unsaturated zone and a lower saturated zone. Infiltrated water percolates into it, and the groundwater can flow to a node of the drainage system. Open the Aquifer Editor from Parameter View ▸ Hydrology ▸ Aquifers. An aquifer is linked to a subcatchment with the Groundwater row (pencil button) in the subcatchment's Properties.

Step by step

  1. Click Parameter View ▸ Hydrology ▸ Aquifers.
  2. Click + to add an aquifer (named AQ1, AQ2 …, filled with the default values below), ⧉ to copy the selected one, or − to delete it.
  3. Select an aquifer in the list and edit its values on the right.
  4. Click OK. Renaming an aquifer also updates the groundwater data of the subcatchments that use it. The change can be undone.

Snow Pack Editor

A snow pack defines how snow accumulates, melts and is removed on the plowable, impervious and pervious parts of a subcatchment. Open the Snow Pack Editor from Parameter View ▸ Hydrology ▸ Snow Packs. Assign a snow pack to a subcatchment with its Snow Pack property. Snowmelt also needs air temperature and the settings on the Climatology Snow Melt and Areal Depletion tabs.

Step by step

  1. Click Parameter View ▸ Hydrology ▸ Snow Packs.
  2. Click + to add a snow pack (named Snow1 …, with default values), ⧉ to copy the selected one, or − to delete it.
  3. Edit the values on the Snow Pack Parameters tab, then the Snow Removal Parameters tab.
  4. Click OK. Renaming a snow pack also updates the subcatchments that use it. The change can be undone.

Unit Hydrograph Editor

A unit hydrograph group describes rainfall-derived inflow and infiltration (RDII): the part of the rainfall that enters the sewer through leaks and illicit connections. Each group has up to three triangular unit hydrographs (short, medium and long term) and can differ per month. Open the Unit Hydrograph Editor from Parameter View ▸ Hydrology ▸ Unit Hydrographs. A node receives RDII through its Unit Hydrograph Group and Sewershed Area properties (RDII group in the Properties pane).

Step by step

  1. Click Parameter View ▸ Hydrology ▸ Unit Hydrographs.
  2. Click + to add a group (named UH1 …, using the first rain gage of the model), ⧉ to copy the selected group, or − to delete it.
  3. Choose the Rain Gage Used. Every group needs a rain gage.
  4. Under Hydrographs For choose All Months or a single month.
  5. Enter R, T and K on the Unit Hydrographs tab and, if needed, the initial abstraction on the Initial Abstraction Depth tab. Switch to another month to enter values for it; the values of each month are kept.
  6. Click OK. Rows that are all zero are not written. Renaming a group also updates the nodes that use it. The change can be undone.

Fields

FieldMeaning
Name of UH GroupUnique name.
Rain Gage UsedRain gage whose rainfall generates the RDII.
Hydrographs ForAll Months or Jan … Dec. Parameters given for a single month replace those of All Months in that month.
RFraction of the rainfall volume that becomes RDII, for the Short-Term, Medium-Term and Long-Term hydrograph.
TTime to the peak of the hydrograph (hours).
KDuration of the falling limb divided by the duration of the rising limb.
Maximum Depth (in, mm)Maximum initial abstraction depth: rainfall that is held back before RDII starts.
Recovery Rate (in/day, mm/day)Rate at which the abstraction capacity recovers in dry weather.
Initial Depth (in, mm)Abstraction depth already used at the start of the simulation.
Tip:

The sum of R of the three hydrographs is the total fraction of rainfall that enters the sewer as RDII. Typical short-term T values are a few hours; long-term values can be a day or more.

Transect Editor

A transect is the measured cross section of a natural channel, given as station/elevation pairs with separate roughness for the left overbank, the right overbank and the main channel. Conduits with the cross section shape Irregular use a transect. Open the Transect Editor from Parameter View ▸ Hydraulics ▸ Transects; pick the transect of a conduit in its Transect property (Cross Section group).

Step by step

  1. Click Parameter View ▸ Hydraulics ▸ Transects.
  2. Click + to add a transect (named TST_1 …), ⧉ to copy the selected one, or − to delete it.
  3. Type the station and elevation of each point in the Data table (30 rows), from left to right looking downstream. The plot below the table is redrawn while you type; the bank stations appear as dashed lines marked L and R.
  4. Enter the roughness, bank stations and modifiers under Properties.
  5. Click OK. Every transect needs at least two points. Renaming a transect also updates the irregular conduits that use it. The change can be undone.

Control Rule Editor

Control rules change the setting of pumps, orifices, weirs and other links during the simulation depending on the state of the system, for example "start the pump when the wet well is deeper than 2 m". Open the Control Rule Editor from Parameter View ▸ Hydraulics ▸ Controls. Each rule is one item in the list; named variables and expressions are shared by all rules.

Step by step

  1. Click Parameter View ▸ Hydraulics ▸ Controls.
  2. Click + to add a rule (named R1 …). A new rule starts with a template: IF NODE DEPTH > 0 / THEN PUMP STATUS = ON / PRIORITY 1. Fill in the object names.
  3. Use ⧉ to copy the selected rule or − to delete it.
  4. Edit the rule in the Control Statement box.
  5. Click Variables to edit the named variables (Named Variables dialog) or Expressions to edit the named expressions (Named Expressions dialog). Enter one definition per line.
  6. Click OK. The rules, variables and expressions are saved together and the change can be undone.

Fields

FieldMeaning
NameUnique name of the rule.
Control StatementThe rule text, without the RULE line: IF condition, optional AND / OR conditions, THEN actions, optional ELSE actions (also joined with AND) and an optional PRIORITY value used when several rules act on the same link at once.
VariablesLines of the form VARIABLE name = object id attribute, for example VARIABLE N1 = NODE J1 DEPTH. The name can then be used in conditions. The word VARIABLE is added if you leave it out.
ExpressionsLines of the form EXPRESSION name = math expression that combine variables, for example the average of two depths. The word EXPRESSION is added if you leave it out.

Example of a complete statement:

IF NODE WW1 DEPTH > 2
THEN PUMP P1 STATUS = ON
ELSE PUMP P1 STATUS = OFF
PRIORITY 1
Note:

When you delete an object from the map, the rules that refer to it (directly or through a variable or expression) are removed as well.

A land use (residential, commercial, roads …) defines how each pollutant builds up on the surface in dry weather and washes off during rain, and how street sweeping removes it. A subcatchment is divided between land uses with the Land Uses row (pencil button) in its Properties, which sets the % of Area of each land use.

Step by step

  1. Define the pollutants first (Pollutant Editor). Without pollutants the editor shows only the General fields.
  2. Click Parameter View ▸ Quality ▸ Land Uses.
  3. Click + to add a land use (named LU_1 …, no buildup or washoff), ⧉ to copy the selected one, or − to delete it.
  4. Fill in the General fields.
  5. Under Pollutant there is one tab per pollutant. On each tab choose the buildup and washoff functions and enter their coefficients. Fields that the chosen function does not use are disabled.
  6. Click OK. Renaming a land use also updates the subcatchment coverages. The change can be undone.

Curve editors

Curves are x–y tables used by many objects: storage volume, pump performance, outlet ratings, custom conduit shapes, tidal stages and more. Each curve type has its own editor. Open one from Parameter View ▸ Curves: Control Curves, Diversion Curves, Pump Curves, Rating Curves, Shape Curves, Storage Curves, Tidal Curves or Weir Curves. In the Properties pane, the ✎ button next to a curve property (for example Pump Curve or Storage Curve) opens the matching editor with that curve selected.

Step by step

  1. Click the curve type under Parameter View ▸ Curves. The list shows only curves of that type.
  2. Click + to add a curve (named CV_1 …), ⧉ to copy the selected one, or − to delete it.
  3. Type the x and y values in the table. A new empty row appears when you type in the last row.
  4. Use the toolbar above the table:
    • Import reads x/y pairs from a text file (.txt, .csv, .dat, .crv). Values may be separated by spaces, tabs, commas or semicolons; lines that do not start with two numbers (for example a header) are skipped.
    • Export writes the table with a header row to .txt (tab-separated) or .csv.
    • Copy puts the table on the clipboard, ready to paste into Excel; Paste replaces the table with x/y pairs copied from Excel.
    • Clear empties the table; View shows the curve as a graph in the Curve Viewer.
  5. For pump curves, choose the pump curve Type (PUMP1 … PUMP5). The column headings and the explanation below the table change with the type.
  6. Click OK. Every curve needs at least one point, all values must be numbers and the x values must increase. A curve name must be unique among all curve types. Renaming a curve also updates the pumps, weirs, outlets, custom conduits, storage units, dividers, outfalls, control rules and LID drains that use it. The change can be undone.

Time Series Editor

A time series is a list of time–value pairs: rainfall for a rain gage, an inflow hydrograph for a node, a tidal level for an outfall, air temperature or evaporation, or an external buildup rate. Open the Time Series Editor from Parameter View ▸ Time Series. The ✎ button next to a time series property in the Properties pane (for example the Time Series of a rain gage or outfall) and in other editors opens it with that series selected.

Step by step

  1. Click Parameter View ▸ Time Series.
  2. Click + to add a series (named TS_1 …), ⧉ to copy the selected one, or − to delete it.
  3. Choose where the data come from: File (an external data file, chosen with …) or Data (the table in the editor). Typing in the table selects Data; choosing a file selects File.
  4. Enter the data in the table: Date (M/D/Y), Time (H:M) and Value. A new empty row appears when you type in the last row.
  5. Use the toolbar:
    • Import reads a text file (.txt, .csv, .dat) with either date time value or time value on each line, separated by spaces, tabs, commas or semicolons. Lines that do not end with a number (such as a header) are skipped.
    • Export writes the series to .dat / .txt (tab-separated) or .csv.
    • Copy puts the table on the clipboard for Excel; Paste replaces the table with rows copied from Excel (three columns date/time/value, or two columns time/value; a header row is skipped).
    • Clear empties the table; View plots the series against elapsed hours. A series used as rainfall by a rain gage is drawn as bars.
  6. Click OK. A series with Data selected needs at least one row, and every row needs a time and a numeric value; a File series needs a file name. Renaming a series also updates the rain gages, outfalls, external inflows, temperature, evaporation, control rules and buildup functions that use it. The change can be undone.

Time Pattern Editor

A time pattern is a set of multipliers that vary a value periodically: dry weather flow over the hours of the day or the days of the week, a baseline inflow, monthly soil recovery, or monthly adjustments of subcatchment parameters. Open the Time Pattern Editor from Parameter View ▸ Time Patterns.

Step by step

  1. Click Parameter View ▸ Time Patterns.
  2. Click + to add a pattern (named PTN_1 …, type MONTHLY, all multipliers 1), ⧉ to copy the selected one, or − to delete it.
  3. Choose the Type. The table changes to 12 months, 7 days or 24 hours; values already entered are kept in order and new rows are set to 1.
  4. Enter the multipliers. Click View to see them as a bar chart.
  5. Click OK. Every pattern must have the full number of numeric multipliers for its type. Renaming a pattern also updates dry weather flows, external inflows, aquifers, the evaporation recovery pattern and subcatchment adjustment patterns. The change can be undone.

Fields

FieldMeaning
Pattern NameUnique name.
DescriptionOptional text, saved as a comment line above the pattern.
TypeMONTHLY – one multiplier per month (Jan–Dec); DAILY – one per day of the week (Sun–Sat); HOURLY – one per hour of the day (12 AM – 11 PM); WEEKEND – hourly multipliers that replace the HOURLY ones on Saturdays and Sundays.

Tip:

For dry weather flow, make the 24 hourly multipliers average 1.0, so that the average value entered at the node stays the true daily average.

Reporting Options

The Reporting Options decide what is written to the status report (.rpt) of a run: the input summary, the control actions, average results and the tables for selected nodes, links and subcatchments. Open them from Parameter View ▸ Options ▸ Reporting. The binary results file always holds every object, so maps, plots and themes are not affected by these settings.

Step by step

  1. Click Parameter View ▸ Options ▸ Reporting. The dialog has the tabs Nodes, Links and Subcatchments.
  2. To report all objects of a kind, tick All Nodes (All Links, All Subcatchments).
  3. To report only some objects, type a name in the box (names are suggested as you type) and click +; or select objects on the map and click Add Map Selection. Adding a name clears the All check box. Unknown names are refused.
  4. To remove names, select them in the list and click −; ✕ clears the whole list.
  5. Tick the report options at the bottom as required, then click OK. The change can be undone.

Fields

FieldMeaning
All Nodes / All Links / All SubcatchmentsReport every object of that kind. When unticked, only the objects in the list are reported; an empty list reports none.
Object listThe objects reported when the All box is not ticked.
Report Input SummaryWrite a summary of the input data at the top of the report.
Report Control ActionsList every action taken by the control rules during the run.

Tip:

For large models, report only a few key objects. Full time series tables for every object make the .rpt file very large without adding information that the results file does not already hold.
