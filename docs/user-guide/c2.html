User interface overview

The Avaris2 CS window has a ribbon at the top, the Designer and Database panes on the left, the map and other views in the centre, docked panes on the right, and a status bar at the bottom.

AreaPurposeSee
RibbonAll commands, grouped on five tabs, plus the quick-access Save, Undo and Redo buttons.Ribbon
Parameter ViewThe non-visual model data: options, climatology, hydrology, hydraulics, quality, curves, time series and patterns.Parameter View
Layer ViewThe map layers: network object types, 2D meshes, added GIS layers and the basemap.Layer View
Database tabThe base model and every simulation run made from it.Database
Map and viewsThe map, plus tabs for attribute tables, the report, profiles, plots and comparisons.Map view
Right panesProperties (with the change Log and Project Description), Catalog, Symbology and Export.Properties pane

You can resize the side panes by dragging their borders. The pane sizes, layer settings and themes are remembered between sessions.

Ribbon

The ribbon groups the commands by task. Large buttons start the most common commands, and small buttons sit next to them. Hover over any button to see a description.

The quick-access toolbar at the top left holds Save (the arrow next to it offers Save As), Undo and Redo.

Project tab

  • File: New, Open, Close.
  • Import and Export: open the Catalog and Export panes.
  • Print: Print Layout – a printable map page with a title block, legend, scale bar and north arrow.
  • User: Switch User and Manage Users (see Sign in and user accounts). The full change history of the model is opened from the Log window (Operation ▸ Change Log, see Change log and history).
  • Settings: Default Settings.

Operation tab

  • Navigate: Pan, Zoom to All, Zoom In, Zoom Out, Zoom to Selection.
  • Bookmarks: Create Bookmark, Manage Bookmarks.
  • Selection: Select, Search, Groups.
  • Edit: Add, Remove, Edit Geometry, Split, Merge, Assign Outlet, Convert Type, Reverse.
  • Display: Theme.
  • Flag: the Flag panel.
  • Change Log: Log Window, History. The Log window's Full Change History… button opens the model change history.

Tools tab

  • Connectivity: Upstream Trace, Downstream Trace, Path, Clear Trace.
  • Network Geometry: Batch Assign Outlet, Recalculate Subcatchment Area, Recalculate Conduit Length, Derive Elevations, Orifice to Conduit, Measure.
  • Model Data: Infer & Clean (fill missing data, find data errors), Dry Weather Flow (generate foul flow and diurnal patterns) and Validate Model.
  • Partition: Partition Model, marked HPS – it belongs to the High Performance Simulation edition.
  • Rainfall: Design Storm.
  • Spatial Reference: Reproject Raster, Convert Coordinates.
  • Utilities: Unit Converter.

Simulation tab

  • Setup: Options, Create Meshes. Create Meshes is marked 1D-2D because it belongs to the 2D flood module.
  • Run: whole model, or coupled parallel when the model has been partitioned.
  • Results: Play, Profile, Plot.
  • Analysis: 2D Flood Analysis (1D-2D), CSO Statistics, Comparison, Report, Convergence.

Help tab

About, Register, User Guide (this guide), Quick Start, Shortcuts and Diagnostics.

Layer View

The Layer View controls what is drawn on the map and in which order.

  • Network: 2D Meshes, Subcatchments, Nodes (Junctions, Outfalls, Storages, Dividers), Links (Conduits, Pumps, Orifices, Weirs, Outlets) and Map Labels. Tick a box to show or hide a layer; the number shows how many objects it holds.
  • Layers: GIS layers you have added, such as Shapefile, GeoJSON, KML, File Geodatabase, GeoTIFF or CSV.
  • Basemap: the online background map.

Layer commands

Right-click a layer for its commands:

  • Zoom to Layer.
  • Select All.
  • Attribute Table.
  • Symbology….
  • Theme….
  • For added layers: Draw Features, Export as Shapefile…, Import into Network…, Move Up / Move Down and Remove.

Double-click a layer to open its symbology. Drag the 2D Meshes and Subcatchments layers to change their drawing order.

The Attribute Table button above the tree opens the table of any layer, including added GIS layers. The + Add Layer button adds GIS data.

Symbology

The Symbology pane sets how a layer is drawn when no theme applies. Open it by double-clicking a layer in the Layer View, from the layer's right-click menu, or from the Symbology tab on the right.

  • Network layers: colour, symbol size or line width, line style, transparency, and the flow direction symbol (style, size, fill). Reset to Default restores the original style. Attribute Table and Theme… open the table and the themes of the layer.
  • Added GIS layers: line and fill colours, fill and layer transparency, line width, point size, and whether the layer is drawn above or below the network. Rasters (GeoTIFF, grids) get a colour ramp.
  • Basemap: the source (OpenTopoMap or OpenStreetMap), transparency, and the model coordinate system (Set…).
  • 2D Meshes: the variable, the rendering (mesh cells or heat map), colour ramp, ranges, transparency, cell outlines and flow arrows; see 2D results.

The preview at the bottom shows the result. Styles are saved with your settings and used for every model.

Map view and navigation

The map draws the network in the model's coordinate system, over an optional basemap, with the legend of the active themes in the lower right.

The eye button and the Locator

Two buttons sit in the top-left corner of the map:

  • The eye button (or the T key) hides all theme and 2D-result colouring, so you see the plain network symbols. Click it again to bring the colours back.
  • The Locator button shows or hides a small overview of the whole model. The red box marks the current view. Click or drag in the Locator to move the map, and roll the wheel over it to zoom.

Select

  • Click an object to select it. Hold Ctrl and click to add objects to the selection.
  • Drag a box to select every object in it.
  • When symbols overlap, hold Shift and click to choose from a list. You can switch this behaviour in Default Settings.
  • Press Esc to clear the selection, or Ctrl+A to select everything.

Hovering over an object shows a tooltip with its ID and its value in the current theme.

Large models

When a model has more than about 60,000 objects and you zoom out, the map shows a pre-drawn overview of the whole network, so zooming and panning stay fast. When you zoom in, the full symbols, labels and themes are drawn again.

Turn on Default Settings ▸ Simplify the map when zoomed out to make panning even smoother.

Properties pane

The Properties pane shows the properties of the selected object, grouped as in Avaris DS:

  • General, with sub-groups such as RDII, Inflows and Infiltration;
  • Statistic Results from the status report after a run.

Click a group header to fold or unfold it.

  • Edit a value: type a new value and press Enter, or pick it from the list. Every change can be undone.
  • Several objects selected: choose the object type at the top. Fields with different values show *Multiple Values, and a value you type is applied to all selected objects of that type.
  • Computed values, such as conduit slope, map length and polygon area, are shown read-only below the editable fields.
  • Filter the change log: click a property name to show only the changes to that variable in the Log below. Click it again to show all changes. The filter is cleared when you select another object.

Below the properties, the Log lists the recorded changes of the selected object. The Project Description box holds the model notes.
