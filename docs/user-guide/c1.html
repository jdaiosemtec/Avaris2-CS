Welcome to Avaris2 CS

Avaris2 CS (Collection System) is a desktop application for planning, analysing and operating urban drainage, storm water and sanitary sewer networks. It combines the Avaris hydraulic engine, built for large and hard-to-converge models, with a GIS map, result analysis tools and an optional 1D-2D surface flood module.

What's new in Avaris2 CS

Avaris2 CS replaces Avaris CS 4.x. It opens the same .inp models, and also reads and writes EPA SWMM 5 and Avaris DS models. The main additions are:

  • Ribbon interface in the style of ArcGIS Pro, with the Project, Operation, Tools, Simulation and Help tabs.
  • Flag panel: 12 built-in warning rules plus your own rules. You can edit their thresholds directly in the rule text, and units follow the model.
  • Layer themes modelled on the InfoWorks ICM theme editor, with time functions (dur, run, win, peak…) that work over the whole simulation.
  • Report viewer with an overview, a water balance, an Insights page and sortable result tables.
  • Scenario comparison with KPI cards, a difference table, a scatter plot and a difference map.
  • GIS: online basemaps, coordinate systems (WKT1/WKT2, State Plane, UTM, Hotine Oblique Mercator), and Shapefile, GeoJSON, KML, File Geodatabase and GeoTIFF layers, each with its own attribute table.
  • Large models: networks with millions of objects stay responsive when you zoom and pan, because a level-of-detail overview is drawn when zoomed out.
  • Users and change history: every edit is recorded with user, time, old value and new value.
  • Avaris engine settings: number of threads, dynamic-wave under-relaxation and an extended non-convergence report.
Note:

Throughout this guide, menu paths are written as Tab ▸ Group ▸ Command. For example, Simulation ▸ Run ▸ Run is the large Run button on the Simulation tab.

Avaris2 CS installs next to Avaris CS 4.x, EPA SWMM and Avaris DS, and does not change their settings or file associations.

Install Avaris2 CS

  1. Download Avaris2CS-Setup-<version>.exe and double-click it. You need administrator rights.
  2. Accept the licence agreement.
  3. Choose the components:
    • Avaris2 CS (required): the program, the Avaris engine and a sample model.
    • Desktop shortcut.
    • Open .inp files with Avaris2 CS (optional): adds Avaris2 CS to the Open with list of .inp files without replacing your default program.
  4. Keep the default folder C:\Program Files\Avaris2 CS, or choose another one, then click Install.
  5. Click Finish to start Avaris2 CS.
"Windows protected your PC"

Microsoft SmartScreen can show this message for newly released programs. Click More info ▸ Run anyway. If you downloaded the installer from a browser, you can also right-click the file, choose Properties, tick Unblock and click OK.

Upgrading

Run the new installer over the existing installation. Avaris2 CS closes a running copy before it replaces the files.

An installation that still carries the earlier name Avaris2 is removed automatically. Your settings, user accounts and change history are kept, because they are stored in your Windows profile and not in the program folder.

Uninstalling

Use Windows Settings ▸ Apps ▸ Avaris2 CS ▸ Uninstall. Your models, results and settings are not deleted.

Sign in and user accounts

Avaris2 CS records who changed a model and when, so every session starts with a sign-in.

The first time the program starts on a computer, it asks you to create an Administrator account. Later starts show the sign-in dialog. Tick Sign in automatically on this computer if you are the only user.

Read-only mode

Without a valid licence, Avaris2 CS runs in read-only mode: you can open and view models and results, but not change, save or run them. This also applies when the licence has expired, was issued for another computer, or when the computer clock has been set back. When you try to edit, save or run, Avaris2 CS tells you why and offers Register….

To get a licence, see Request and activate a licence.

Check your licence

Help ▸ Register shows the licence of this computer at the top: edition, licensee, expiry date, days left and serial number. The window title shows the edition (1D, 1D-2D or HPS).

Upgrades and reinstalling

The licence is stored with your Windows user settings, not in the installation folder. Installing a new version, uninstalling and reinstalling, or installing into another folder keeps the licence; you do not need to request a new one.

If the settings were deleted (for example by a clean-up tool) or you sign in to Windows with another user account, Avaris2 CS starts read-only again. Activate the same licence key again in Help ▸ Register: it stays valid on this computer until its expiry date. Keep the e-mail or the .avlic file you received from OSEMTEC.

Move a licence to another computer

  1. On the old computer, click Help ▸ Register ▸ Release this Computer… and confirm. Avaris2 CS shows the licence serial, the machine code and a release code, and runs read-only from then on.
  2. On the new computer, send a licence request (see Request and activate a licence) and add the release code to the e-mail.
  3. Activate the new licence key that OSEMTEC sends you.
Note:

The machine code is calculated from the Windows installation, the system drive and the network adapters; two of the three must match. Adding a docking station, a VPN or switching between Wi-Fi and cable does not change the licence. Reinstalling Windows, replacing the system drive or the main board, or a new computer needs a new licence: send a new request.

  • Install Avaris2 CS on the computer that will use the licence, and sign in.

  5. Click Send by E-mail, check the e-mail and press Send in your mailbox.

OSEMTEC checks your account and purchase and replies to the e-mail address in the request. The e-mail contains the edition, the validity period, the serial number and the licence key, a long text starting with AV2L-; it may also have the key as an .avlic file.

If OSEMTEC asks for it, send a new request first.

Quick-start tutorial

This tutorial walks you through the basic workflow: open a model, check it, run it, and read the results on the map, in graphs and in the report.

1. Open a model

  1. Start Avaris2 CS and sign in. The start dialog lists recently used models.
  2. Click Open Sample to copy the sample model to Documents\Avaris2 CS\Samples and open it. To open your own model, click Open Model… and pick any EPA SWMM 5.x or Avaris .inp file.

2. Look around the map

Roll the mouse wheel to zoom, and drag with the middle mouse button (or hold Space and drag) to pan. Press Home to see the whole model. The Locator in the top-left corner of the map shows where you are.

Click an object to see its properties in the Properties pane on the right. Edits you make there are applied immediately and can be undone with Ctrl+Z.

3. Check and run

  1. Click Tools ▸ Model Data ▸ Validate Model to check for missing references, disconnected nodes, zero lengths and similar problems.
  2. Review the settings in Simulation ▸ Setup ▸ Options: simulation dates, time steps and routing method.
  3. Click Simulation ▸ Run ▸ Run (or press F5) and give the run a name, for example Design 10yr.

Each run is saved in the <model>_Results folder next to the model and listed in the Database pane, so you can keep and compare as many runs as you need.

4. Look at the results

  • Play the results with Simulation ▸ Results ▸ Play. The map is coloured by the current depth and flow.
  • Open the Report for continuity errors, flooding and surcharge summaries.
  • Select two nodes and click Profile for a long section, or select objects and click Plot for time series graphs.
  • Open the Flag panel to highlight flooding, surcharge and capacity problems at once.
Tip:

Help ▸ Quick Start shows a one-page summary of these steps inside the program, and Help ▸ Shortcuts lists the keyboard shortcuts.
