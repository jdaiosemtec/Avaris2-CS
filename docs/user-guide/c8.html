Play results

Simulation ▸ Results ▸ Play opens the playback bar below the map. The map then shows the results at the current time step, using the themes marked ▶ (time-varying).

  • ▶ / ❚❚ plays or pauses; ◀ / ▶ step back or forward by one reporting step. Drag the slider to jump to any time.
  • Choose the speed: Slow, Normal, Fast or Very fast.
  • Theme… opens the Layer Theme Editor.
  • Peak ▾ jumps to the time of a system peak: rainfall, runoff, total lateral inflow, flooding, system outflow or storage volume. With an object selected, it can also jump to that object's own peaks.
  • ✕ Quit closes play mode. The results stay loaded, and the map returns to the themes for whole-run values.

The legend in the lower right of the map lists the active themes. Hover over any object to read its current value. The Properties pane of a selected object shows its Statistic Results from the status report and a small results card.

Themes

Themes colour and size nodes, links and subcatchments by any attribute, computed value, simulation result or expression. Open the Layer Theme Editor with Operation ▸ Display ▸ Theme, from the playback bar, or by right-clicking a layer.

How themes combine

  • Each layer (Nodes, Links, Subcatchments) has an ordered list of themes above a Base Theme, which gives each object type its own colour.
  • Themes are applied from the top down: the first enabled theme that sets the colour, or the size or width, of an object wins.
  • Themes marked ▶ use results at the current time step and are shown only in play mode. The others are shown outside play mode.
  • A Where condition limits a theme to some objects, for example type = 'CONDUIT' and diam >= 1.

Flags

Flags are ready-made warning rules that colour the problem objects of a simulation, for example nodes that flood, pipes over capacity or sewers that silt up. Each rule has up to three levels: Warning, High and Critical. You can adjust the thresholds directly in the rule text, and edit the rules themselves.

The Flag panel

Open the panel with Operation ▸ Flag ▸ Flag.

  • Flags are grouped by layer: Nodes, Links and Subcatchments. Choose one flag per layer with its radio button, so up to three flags can be shown at the same time. Choose None to show no flag on that layer.
  • While any flag is shown, all ordinary themes are suspended. Close the panel, or set every layer to None, and the themes come back.
  • The numbers in the rule text are edit boxes. Type a new threshold and press Enter; the map updates at once. Changed values are highlighted. To return to the default value, type it again.
  • Units follow the model: feet and ft/s for CFS, GPM and MGD; metres and m/s for CMS, LPS and MLD. When you change the flow units, the thresholds are converted.
  • ▶ / Σ chooses how the flag is shown:
    • ▶ shows the level at the current time step, during playback;
    • Σ shows the worst level reached during the whole run, outside playback.
  • Click the colour strip of a flag to change the colour of each level.

Colours

The colour dialog shows a short description of the flag and, for each level, its colour and the condition that sets it. To change the conditions, use Edit…. Tick No fill for Normal to keep the usual symbol for objects that are not flagged.

Create your own flag

  1. Click + New flag.
  2. Enter a name, the layer, the display mode, a short description and the rule text. Write each number the user may change as {name}, without its unit.
  3. Click Next: conditions….
  4. Write the condition of each level in the expression language. Refer to parameters as $name, and click a field or function on the right to insert it. Levels are checked from Critical down, and the first true condition sets the level.
  5. Enter the default value and unit of each parameter, and optionally a Where condition, then click Add flag.

Your own flags can be edited or deleted with the links under them. Export… and Import… share flags between models and colleagues. All flag settings are saved with the model in Model.flags.json.

Edit a built-in flag

Every built-in flag can be changed, not only its thresholds. Click Edit… under the flag to change its name, description, rule text, the condition of each level, the Where condition and the default values of its parameters (US and SI).

  • Conditions use the expression language. $name is a parameter of the rule text; $eps (smallest flow counted as flow) and $tol (level tolerance) are set by Avaris2 CS for the model units.
  • Copy Conditions copies the conditions as text, one line per level. Paste Conditions… takes such text, for example a rule sent to you by OSEMTEC or a colleague: 
    High: totdur(abs(rptFlow) > $eps) >= $n and 100 * dur(rptFlow < -$eps) / totdur(abs(rptFlow) > $eps) >= $h
Warning: totdur(abs(rptFlow) > $eps) >= $n and 100 * dur(rptFlow < -$eps) / totdur(abs(rptFlow) > $eps) >= $w
Where: type = 'CONDUIT'
  • If a condition has an error, the dialog shows the level and the problem, and nothing is changed.
  • An edited flag is marked edited in the panel. Changes to built-in flags apply to all models on this computer. Click Reset to restore the original flag.
  • Export… includes your edits of built-in flags, and Import… applies them on another computer.

Accuracy

Durations are counted in reporting steps. With a 15-minute reporting step, a condition that is true at one step counts as 15 minutes. Use a shorter reporting step for more precise durations.

Profile (long section)

Select two nodes, or a chain of links, and click Simulation ▸ Results ▸ Profile. The profile follows the flow path between them and shows:

  • the ground, manhole shafts and pipes;
  • the water level at the current time (HGL);
  • the maximum HGL.

A table of node and link values sits above the graph.

  • Play animates the water level along the profile, in step with the map.
  • Options chooses what is drawn (node labels, max HGL, EGL) and which rows the information table shows.
  • Export CSV saves the table, and Select on Map selects the profile objects.

Time series plots

Select one or more objects and click Simulation ▸ Results ▸ Plot. Choose the object type, the variable and the time axis (elapsed hours or date and time). You can tick Overlay comparison run to draw a second run as dashed lines.

Hover over the graph to read values. Drag to zoom in, and double-click to reset the zoom. Export CSV and Save PNG export the graph. The rainfall of a rain gage is drawn as an inverted bar chart; you can change this in Default Settings.

Scenario comparison

Simulation ▸ Results ▸ Comparison compares two runs: two scenarios, or two runs of the same model. Load the second run from the Database (Add to Comparison), or use Run Selected & Compare in the Scenarios panel.

  • Base and Compare choose the two runs; ⇄ swaps them.
  • KPI cards compare the system totals: flood volume, flooded and surcharged nodes, surcharged conduits, outfall volume, surface runoff and continuity error.
  • The difference table compares one variable (max HGL, max depth, freeboard, flood volume, hours flooded, max flow, capacity…) object by object, within a tolerance. Each object is marked Worse, Better, New (for example, newly flooding), Resolved or No change. Tick Changed only to hide the unchanged objects.
  • The scatter plot draws base against compare. Points above the 1:1 line are higher in the compare run. Click a point to select the object.
  • Difference on Map colours the map by the change, and Graph Selected plots both runs for the selected objects.
