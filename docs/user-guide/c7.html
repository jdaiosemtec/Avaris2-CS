Simulation options

Simulation ▸ Setup ▸ Options opens the Simulation Options dialog. Its tabs follow the [OPTIONS] section of the .inp file, plus tabs for the Avaris engine, object defaults and 2D flooding.

General

On this tab you set:

  • flow units;
  • routing model: Steady, Kinematic Wave or Dynamic Wave;
  • infiltration model: Horton, Modified Horton, Green-Ampt, Modified Green-Ampt or Curve Number;
  • link offsets (depth or elevation);
  • minimum conduit slope, ponding and skipping steady-state periods;
  • which process models to ignore: rainfall/runoff, snowmelt, groundwater, RDII, flow routing or water quality.

Dates and time steps

Set the start and end of the analysis, the start of reporting, the street-sweeping period and the antecedent dry days. Then set the reporting step, the wet-weather and dry-weather runoff steps, the routing step, the control rule step and the steady-state tolerances.

Note:

The reporting step decides how many time steps are saved in the results file. It also sets the accuracy of the time functions used by themes and flags: 15 minutes is a good compromise for most storm events.

Dynamic Wave

The dynamic-wave settings are:

  • inertial terms;
  • normal flow criterion;
  • force main equation;
  • surcharge method (EXTRAN or SLOT);
  • variable step safety factor;
  • minimum variable step;
  • conduit lengthening step;
  • minimum nodal surface area;
  • maximum trials per step;
  • head convergence tolerance.

Avaris Engine

SettingMeaning
Number of ThreadsConduit flows and node depths are solved in parallel with OpenMP; 0 uses all cores. Detect & Recommend proposes a value for this computer. Results are identical for any number of threads. Models with fewer than 4 links per thread run on one thread.
Under-Relaxation FactorThe weight given to the new value in each dynamic-wave iteration (0.1–1.0). The standard value is 0.5. Lower values damp oscillation at hard-to-converge nodes; higher values converge faster on well-behaved networks.
Nonconverging Nodes Listed in ReportLength of the "Most Frequent Nonconverging Nodes" list in the report. The standard report lists 5; Avaris lists up to 500.
Write time-series tables to report fileOff by default. Results are read from the binary file, which keeps the report small for large models.

Object Defaults

Default values for new nodes, conduits and subcatchments: depths, diameter, roughness, length, area, width, imperviousness and slope. They are saved with your Avaris2 CS settings, not in the model.

2D Flood

The settings of the 1D-2D flood module. See Set up a 2D model.

Run a simulation

  1. Click Simulation ▸ Run ▸ Run or press F5. Avaris2 CS first runs the quick checks of Validate Model and shows any problems, with the choice to run anyway.
  2. Enter a simulation name and an optional description. Click an existing name to reuse it, which replaces that run.
  3. Watch the progress. Click Stop to cancel. If 2D flooding is enabled but no mesh exists yet, you can create the mesh first or run the 1D model only.

When the run finishes, the results are loaded automatically. The status bar shows the number of reporting steps, and a summary lists the continuity errors, flooding and warnings.

Whole model or coupled parallel

When the model has been partitioned (Model partition, HPS edition), the Run dialog has a Run section: Whole model runs the model as usual, Coupled parallel runs the sub-models at the same time on several processor cores. See Coupled parallel simulation.

Results and play mode

Loading results does not start the animation: the map shows the results at the current time, and statistic themes (max. depth, max. capacity) work straight away. Click Simulation ▸ Results ▸ Play to enter play mode and animate the run; click it again to leave play mode.

Convergence diagnostics

After a dynamic-wave run, Simulation ▸ Analysis ▸ Convergence lists the nodes where the engine most often failed to converge, with the share of steps not converged and any orifices next to them. It also shows the routing time step summary from the report.

Color Map by Nonconvergence shows on the map where the problem is concentrated, and Select All Listed selects those nodes.

Reducing non-convergence
  • Convert problem orifices to equivalent conduits (Orifice to Conduit).
  • Lower the under-relaxation factor, for example to 0.3.
  • Check very short conduits and large steps in invert levels.
  • Re-run and compare the hydrographs to confirm that the results did not change materially.

2D flood modelling overview

🔒 Avaris2 CS 1D-2D

The 2D flood module covers the ground surface with a mesh of square cells, coupled to the manholes of the pipe network. Water that surcharges out of a manhole flows over the surface, following the terrain, and can re-enter the network downstream.

How it works

  • A 2D boundary polygon defines the area. Its attributes set the cell size (length) and the Manning roughness of the ground (roughness).
  • The cells take their ground elevation from a DEM (GeoTIFF or ASCII grid).
  • Optional water front lines let surface water leave the model, for example at a river bank or coast. Cut-off lines block flow across walls and embankments, and exclusion polygons remove buildings and other areas without cells.
  • Every junction, storage unit or divider tagged Link2D is coupled to the cell it lies in.
  • The cells and the surface links between them are added to a copy of the model (.finp) and simulated together with the pipe network by the Avaris engine. The approach is compatible with Avaris DS, so models with 2D settings in the Avaris DS project file (.ini [2D]) are taken over automatically when you open them.

Set up a 2D model

  1. Open Simulation ▸ Options ▸ 2D Flood and tick Enable 1D-2D flood simulation.
  2. Choose the input layers:
    • 2D Boundary (polygon);
    • Digital Elevation Model;
    • optionally the Water Front, Cut-off Lines and Exclusion Polygons.
    Paths inside the model folder are stored as relative paths.
  3. Set the cell size and roughness, or leave them blank to use the boundary attributes.
  4. Set the Mesh Units:
    • MODEL, as in Avaris DS, uses the values as they are;
    • CONVERT converts them from the map units to the model units, for example a metre DEM in a US-units model.
  5. Tick Tag all nodes "Link2D" to couple every manhole, or tag selected nodes yourself.
  6. Click Simulation ▸ Setup ▸ Create Meshes. The mesh is saved as Model.mesh2d.json and appears as the 2D Meshes layer, coloured by ground elevation.
  7. Run the simulation. 1D-2D runs write .finp, .frpt and .fout files.
Note:

Rebuild the mesh after you change the boundary, DEM, cell size, exclusions or the Link2D tags.

2D results

After a 1D-2D run, the 2D Meshes layer shows the flooding on the surface. All 2D statistics (depths, velocities, hazard, times) are calculated from the results file when the results are loaded; you do not need to run again to see a new variable.

Mesh cells or heat map

Rendering in the Symbology pane sets how the values are drawn:

  • Mesh cells (ranges): each cell is filled with the colour of the range its value falls in. Exact, and best for reading values cell by cell. Cell outlines draws the cell borders.
  • Heat map (smooth): a continuous surface in which the colours blend between the ranges and the edge of the flooded area is soft. Best for presentations and for seeing the overall pattern. The legend becomes a colour bar. The heat map also animates in play mode.

Both renderings use the same ranges and colour ramp: set the number of ranges and click Auto-Theme, or type the values and pick colours one by one; Reset returns to the defaults. Cells below the first value are left uncoloured (dry). Transparency lets the basemap show through.

Hazard rating

The hazard rating follows the UK Defra / Environment Agency method (FD2320): HR = d × (v + 0.5) + DF, with the depth d in metres and the velocity v in m/s (US models are converted). The classes are:

HRClassMeaning
< 0.75LowCaution – flood zone with shallow or slow water.
0.75 – 1.25Danger for someDangerous for children, the elderly and the infirm.
1.25 – 2.0Danger for mostDangerous for most people, including the general public.
> 2.0Danger for allDangerous for everyone, including the emergency services.

The debris factor DF is chosen in the Symbology pane when a hazard variable is shown, or in the 2D Flood Analysis: Conservative (0.5 up to 0.25 m depth, 1.0 above; the default), Pasture / arable (0 up to 0.25 m, 0.5 above) or None. Only cells deeper than the Flood Depth Threshold are rated.

Flow direction arrows

Tick Flow direction arrows in the Symbology pane (or right-click the 2D Meshes layer ▸ Flow Direction Arrows). Arrows point in the flow direction and grow with the speed. They are drawn on cells at least 12 pixels wide, so zoom in to see them. Outside play mode they show the direction at the maximum velocity; in play mode, the current flow.

Cell values and the 2D cell graph

Hover over a cell to read its values. Click a cell: Properties lists all its statistics (ground level, max. depth, velocity, hazard, arrival time…). Click 2D Cell Graph there for three linked graphs over time – depth (with the flood threshold), velocity and hazard rating (with the 0.75 / 1.25 / 2.0 class lines). Drag to zoom, double-click to reset.

Attribute table and exports

Right-click the 2D Meshes layer for:

  • Attribute Table: one row per cell with every result column; sort, filter and export it.
  • Export as Shapefile…: the cells as polygons with all results.
  • Export Flood Extent (Shapefile)… and Export Hazard Classes (Shapefile)…: merged polygons; see Flood exports.
  • Export Max. Depth (GeoTIFF)… and Export Raster of a Field….
  • 2D Flood Analysis… and 2D Cross Section.

2D Flood Analysis

Simulation ▸ Analysis ▸ 2D Flood Analysis (1D-2D edition) summarises the flooding of the loaded 1D-2D run: how much area floods, how deep and how dangerous, where, and how it changes between two runs.

Key figures

Flooded at depth ≥ sets the depth from which a cell counts as flooded (default: the Flood Depth Threshold). The cards then show the flooded area (and the share of the mesh), flooded cells, max. depth, max. velocity, max. hazard rating with its class, the area with HR ≥ 0.75 and the earliest arrival time. Debris factor changes the hazard rating everywhere.

Area by class

Area by max. depth uses the ranges of the 2D Meshes layer (change them in Symbology), and Area by max. hazard rating uses the four Defra classes. Each row gives the area and the share of the flooded area.

Statistics by zone or point

Use your own areas or assets to report the flooding: districts, land parcels, catchments, buildings, schools, roads.

  1. Load a polygon or point layer with Add Layer… (here or in the Layer View), or draw one (Layer View ▸ right-click ▸ New Layer). It must be in the coordinate system of the model and cover the 2D mesh.
  2. Choose it in Layer, and in Name field the attribute that names each feature.
  3. For polygons you get one row per polygon from the cells whose centre lies inside it: area, flooded area and %, max. and mean depth, max. velocity, max. hazard rating, earliest arrival and time ponded. For points you get the values of the cell under each point. The header counts the flooded and dangerous zones.
  4. Double-click a row to zoom to it. Export ▸ Zone statistics (CSV) writes the table.

The table refreshes by itself when a layer is added or removed.

Compare two 1D-2D runs

  1. Click Compare… and choose another 1D-2D run of the same mesh (or a .fout file). Cells are matched by ID.
  2. The Scenario Comparison opens with the other run as Base, this run as Compare and 2D Cells as the object type. The 2D key figures are highlighted at the top: flooded area and cells, max. depth and velocity, area HR ≥ 0.75 and ≥ 2, earliest arrival – each with the change and the change in %.
  3. The table lists the cells that changed (Worse, Better, New = newly flooded, Resolved = no longer flooded). Choose another variable (max. velocity, hazard, depth × velocity, arrival, time ponded) in the variable list.
  4. Difference on Map colours the mesh by the depth difference (variable Max. Depth Difference, green = shallower, red = deeper).

2D cross section

Click Cross Section (or right-click the 2D Meshes layer ▸ 2D Cross Section), then click the vertices of a line on the map; double-click or press Enter to finish, Esc to cancel. The graph shows the ground and the max. water surface along the line (and of the compared run, if any); in play mode also the current water surface. Gaps are outside the mesh.
