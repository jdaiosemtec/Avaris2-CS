Connectivity: trace and path

  • Upstream Trace and Downstream Trace (Tools ▸ Connectivity) select and highlight every node and link upstream or downstream of the selected node or link. The status bar sums the trace: number of objects, conduit length and contributing subcatchment area.
  • Path opens a small panel: click the start node and the end node on the map, and the path between them is highlighted and selected. Untick Directed to allow paths against the flow direction.
  • Clear Trace removes the highlight.
Tip:

After a trace, open Groups ▸ Create Group… to save the traced catchment, or open the attribute table with Selected only ticked to review it.

Network geometry tools

Batch Assign Outlet

Assigns the outlet node of many subcatchments at once. Each subcatchment drains to the node with the lowest invert inside its polygon, or to the nearest node if there is none inside. You can apply it to all or only the selected subcatchments, and limit it to subcatchments without a valid outlet.

Recalculate Subcatchment Area / Conduit Length

These tools recompute the areas from the polygons and the lengths from the drawn lines, in map units. Set Map Units in the status bar first. For conduits you can set a minimum length.

Derive Elevations (design inverts)

Designs invert elevations for a tree-shaped (dendritic) network from the rim levels:

  • Ground level at each node is the current invert plus its maximum depth.
  • The deepest conduit at each node keeps the minimum cover over the pipe crown.
  • Inverts are worked downstream from the most upstream nodes so that every conduit keeps at least the minimum slope.
  • Where needed, drop structures (inlet offsets) are used.

Max. depths and conduit offsets are updated to match. A network that contains a loop is rejected.

Orifice to Conduit

In dynamic-wave models, orifices are a frequent cause of non-convergence. This tool replaces them with short equivalent conduits that behave like orifices:

  • the same cross section and inlet invert;
  • a length of 10 ft (3.048 m);
  • entry loss 0.5, exit loss 1.0, Manning's n 0.013.

Orifices used by control rules can be skipped, and the new conduits are tagged so you can find them.

Measure

Click points on the map to measure a distance in map units. Double-click to finish.

Infer & Clean: missing data and data errors

Models built from GIS or asset records often have gaps: pipes without a diameter, manholes without an invert, zero lengths. Tools ▸ Model Data ▸ Infer & Clean finds the missing values, proposes a value for each one from its neighbours, and lists data errors. Nothing is changed until you click Apply Ticked, and the whole change is one undo step.

Settings

SettingMeaning
0 is missing / and ≤Which values count as missing. With 0 is missing ticked, a zero counts as missing. Values at or below the second number (for example -999, a common “no data” code) also count as missing. An empty field is always missing.
Min. slope (%)Used when an invert is known on one side only: the invert is extended from the known end at this slope.
Default nManning's n used when no connected conduit has a roughness.
ToleranceTolerance of the checks, in model length units (for example how far a downstream invert may be above the upstream one before it is reported as an adverse slope).
DEM (optional)A ground model (GeoTIFF or ASCII grid). With a DEM, node inverts are inferred as ground − manhole depth, which is much more accurate than interpolation, and missing manhole depths can be filled in. Click … to choose the file.
Tag changed objectsOptional. A tag (for example INFERRED) that is written to every object that gets an inferred value, so you can find, theme or review them later.

How values are inferred

ValueRule
Conduit lengthLength of the conduit as drawn on the map (in map units; set Map Units in the status bar first).
Conduit size (geom 1)The largest upstream conduit; if there is none, the smallest downstream conduit. Repeated along chains, so a run of several pipes without size fills from its known ends. Irregular, street and dummy sections are skipped.
RoughnessThe most common value of the connected conduits, otherwise Default n.
Node invertWith a DEM: ground − manhole depth. Without: interpolated by pipe length between the nearest known inverts upstream and downstream. If only one side is known, extended at Min. slope.
Manhole depth (DEM)DEM ground − invert, only where the depth is missing.

Steps

  1. Save the model (or save a copy with Save As) so you can go back.
  2. Open Tools ▸ Model Data ▸ Infer & Clean, check the settings and choose a DEM if you have one.
  3. Click Analyse. The left table lists every value that can be inferred: object, field, current value, inferred value and how it was found. The right table lists the issues. The status bar gives the counts.
  4. Review the values. Click a row to select the object; double-click to zoom to it on the map. Sort by a column by clicking its header.
  5. In the Apply row, tick the kinds of values you want to write (length, size, roughness, invert, depth). The number in brackets is how many values of that kind were found.
  6. Click Apply Ticked. All ticked values are written in one step, recorded in the change history, and can be undone with Ctrl+Z.
  7. Use Export CSV to keep a record of the inferred values and the issues for your report.

Data errors found

The issues are reported only; they are not changed automatically, because the right fix depends on the cause. The buttons next to the Issues title select all objects of one kind at once, so you can review them in the attribute table or theme them.

Important:

Inferred values are estimates. Use them to get a model running and to find gaps, then confirm the important ones (trunk sewers, outfalls, structures) against survey or record drawings.

Dry Weather Flow

Tools ▸ Model Data ▸ Dry Weather Flow generates the foul (sanitary) flow of the nodes from population or area loads, adds base infiltration, and writes a diurnal pattern. The result goes into the node's dry weather inflow and the time patterns, in one undoable step.

Where the loads come from

Loads fromHow the flow is calculatedNode that receives it
SubcatchmentsBasis: population density × per-capita flow (persons/ha × L/person/day, or the US equivalents), or area × unit flow (flow per hectare or acre).The outlet node of the subcatchment. If the outlet is another subcatchment, it is followed until a node is reached.
GIS layer (points / polygons)A numeric attribute of the layer, read as population, households (× persons per household) or a flow directly.The outlet of the subcatchment that contains the feature, otherwise the nearest junction; or always the nearest junction.

Other settings

  • Only subcatchments: an expression that limits the subcatchments, for example tag = 'RES' or imperv > 30 (see Expression language). Empty = all.
  • Infiltration: a base infiltration added as a percentage of the foul flow.
  • Existing DWF: what happens to dry weather flow already in the model – replace it at the nodes that get a load, add to it, only fill nodes without dry weather flow, or clear all dry weather flow first.

Diurnal pattern

  • Template: Residential, Commercial, Industrial, Flat or Custom. The 24 hourly multipliers can be edited directly in the table; the graph below shows the shape.
  • weekend pattern: adds a second row of multipliers for Saturday and Sunday.
  • Pattern name: the patterns are written as <name>_HR (hourly, used Monday to Friday) and <name>_WE (weekend). The multipliers are scaled to an average of 1, so the daily volume equals the average flow × 24 h. A pattern with the same name is replaced.

The Result section at the bottom updates as you change the settings: subcatchments used, nodes that get dry weather flow, population, average flow and daily volume, and a table per node. Click Apply to write it.

Different land uses

Each node has one dry weather flow pattern. To give residential, commercial and industrial areas their own flow rates:

  1. Tag the subcatchments by land use, for example RES, COM, IND (attribute table or Properties).
  2. Run the tool with Only subcatchments = tag = 'RES', the residential rates and template, pattern name RES, Existing DWF = replace.
  3. Run it again with tag = 'COM', the commercial rates and template, pattern name COM, Existing DWF = add.
  4. Repeat for the other land uses. Where two land uses drain to the same node, the node keeps the pattern of the last run, so use land-use boundaries that follow the drainage where you can.

Check the result

  • Select a node and open Inflows ▸ Dry Weather in Properties to see the average flow and pattern names; the patterns are under Hydrology ▸ Time Patterns in the Parameter View.
  • Run a dry period and check the Dry Weather Inflow line of the continuity table in the report against the daily volume shown in the dialog.
  • Plot the total inflow of an outfall: it should show the daily cycle.

Validate the model

Tools ▸ Model Data ▸ Validate Model checks the model and lists the problems in a Validation view. The counts of errors, warnings and notes are shown at the top.

  • Errors:
    • links whose inlet or outlet node does not exist;
    • conduits with zero length or zero depth;
    • a pump curve, rain gage, time series or subcatchment outlet that is not defined;
    • a conduit that starts and ends at the same node.
  • Warnings:
    • nodes not connected to any link;
    • adverse (negative) conduit slopes.
  • Notes:
    • junctions with zero depth;
    • a conduit crown above the rim of its upstream node;
    • very short conduits that can limit the time step;
    • orifices in dynamic-wave models.

Click a row to select the object and zoom to it, and click Re-check after fixing problems. Errors stop a simulation; the quick checks also run automatically before each run. For missing values and more data checks, use Infer & Clean.
