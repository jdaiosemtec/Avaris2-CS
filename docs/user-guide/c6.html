Connectivity: trace and path

  • Upstream Trace and Downstream Trace (Tools ▸ Connectivity) select and highlight every node and link upstream or downstream of the selected node or link. The status bar sums the trace: number of objects, conduit length and contributing subcatchment area.
  • Path opens a small panel: click the start node and the end node on the map, and the path between them is highlighted and selected. Untick Directed to allow paths against the flow direction.
  • Clear Trace removes the highlight.
Tip:

After a trace, open Groups ▸ Create Group… to save the traced catchment, or open the attribute table with Selected only ticked to review it.

Network geometry tools

Batch Assign Outlet

Assigns the outlet node of many subcatchments at once. Each subcatchment drains to the node with the lowest invert inside its polygon, or to the nearest node if there is none inside. You can apply it to all or only the selected subcatchments, and limit it to subcatchments without a valid outlet.

Recalculate Subcatchment Area / Conduit Length

These tools recompute the areas from the polygons and the lengths from the drawn lines, in map units. Set Map Units in the status bar first. For conduits you can set a minimum length.

Derive Elevations (design inverts)

Designs invert elevations for a tree-shaped (dendritic) network from the rim levels:

  • Ground level at each node is the current invert plus its maximum depth.
  • The deepest conduit at each node keeps the minimum cover over the pipe crown.
  • Inverts are worked downstream from the most upstream nodes so that every conduit keeps at least the minimum slope.
  • Where needed, drop structures (inlet offsets) are used.

Max. depths and conduit offsets are updated to match. A network that contains a loop is rejected.

Orifice to Conduit

In dynamic-wave models, orifices are a frequent cause of non-convergence. This tool replaces them with short equivalent conduits that behave like orifices:

  • the same cross section and inlet invert;
  • a length of 10 ft (3.048 m);
  • entry loss 0.5, exit loss 1.0, Manning's n 0.013.

Orifices used by control rules can be skipped, and the new conduits are tagged so you can find them.

Measure

Click points on the map to measure a distance in map units. Double-click to finish.

Validate the model

Tools ▸ Utilities ▸ Validate Model checks the model and lists the problems in a Validation view.

  • Errors:
    • links whose inlet or outlet node does not exist;
    • conduits with zero length or zero depth;
    • a pump curve, rain gage, time series or subcatchment outlet that is not defined;
    • a conduit that starts and ends at the same node.
  • Warnings:
    • nodes not connected to any link;
    • adverse (negative) conduit slopes.
  • Notes:
    • junctions with zero depth;
    • a conduit crown above the rim of its upstream node;
    • very short conduits that can limit the time step;
    • orifices in dynamic-wave models.

Click a row to select the object and zoom to it, and click Re-check after fixing problems. The quick checks also run automatically before each simulation.
