Time functions

Time functions read every reporting step of the loaded results. All durations are in minutes, and c is a condition.

FunctionReturnsChanges with the time step?
dur(c)Total time c was true from the start up to the current time stepYes
run(c)How long c has been true without a break at the current time step (0 when false now)Yes
win(c, W)Time c was true within the last W minutesYes
totdur(c)Total time c was true in the whole simulationNo
maxrun(c)Longest uninterrupted period c was trueNo
maxwin(c, W)Most time c was true within any W-minute windowNo

Expressions that change with the time step are shown during playback (▶). Whole-run expressions are shown outside playback. The first use of a time function reads the results once in the background; later uses are instant.

The Avaris engine

Avaris2 CS runs simulations with the Avaris hydraulic engine: a dynamic-wave, kinematic-wave and steady-flow solver for urban drainage networks, with rainfall-runoff, infiltration, groundwater, snowmelt, RDII, LID and water quality. Compared with standard solvers for the .inp format, it adds:

  • Coupled parallel simulation of a partitioned model (HPS edition): one engine process per sub-model, exchanging flow and water level at the cut points in every iteration; see Coupled parallel simulation.
  • User-set under-relaxation of the dynamic-wave iterations (UNDER_RELAXATION, 0.1–1.0; the standard value is 0.5).
  • Parallel node-depth solution with OpenMP, with per-node convergence flags. The results do not depend on the number of threads.
  • Extended non-convergence report: up to 500 nodes in "Most Frequent Nonconverging Nodes" (NONCONV_REPORT_COUNT). Outfalls are excluded from the statistics.
  • An optional compact report that leaves out the time series tables.
  • Sections the engine does not use, such as [GROUPS] written by Avaris DS, are skipped instead of causing an error.
  • Manhole chamber area and an impervious runoff coefficient per subcatchment, read from the ;;@OSEM comment lines.
  • The 2D surface mesh for 1D-2D runs.

A model saved by Avaris2 CS can also be run by EPA SWMM 5.2. The Avaris-specific settings are then ignored.

Troubleshooting and FAQ

Windows shows "Windows protected your PC" when I install

Click More info ▸ Run anyway. See Install Avaris2 CS.

The basemap is empty or in the wrong place

The basemap needs an internet connection and a correct coordinate system. Open the coordinate system dialog and check where the model centre lands. A wrong .prj file next to the model is the most common cause. See Coordinate systems and basemaps.

A large model is slow to zoom and pan

  • Turn on Default Settings ▸ Simplify the map when zoomed out.
  • Hide the layers you do not need, such as subcatchments or labels.
  • Help ▸ Diagnostics shows the time each step takes. Copy the table and send it to support.

The simulation has a high continuity error or many non-converging steps

  • Use Convergence diagnostics to find the problem nodes.
  • Convert orifices to equivalent conduits.
  • Lower the under-relaxation factor, and check very short conduits.

Flags show nothing

  • Load results first.
  • A flag set to ▶ is shown only during playback, and a flag set to Σ only outside playback.
  • Flags that use durations need a moment to read the results the first time; the status bar shows the progress.

My themes disappeared

  • Themes are suspended while a flag is shown: close the Flag panel.
  • The eye button (T) may also be hiding the colouring.

Avaris2 CS opens read-only

The message in the read-only notice tells you why: no licence, an expired licence, a licence for another computer, or a computer clock set earlier than the last use. See Licensing and registration.

Where are my settings stored?

In %APPDATA%\OsemCM: user accounts, recent files, layer styles, themes and preferences. Model-specific settings are stored next to the model.
