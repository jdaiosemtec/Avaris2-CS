Select, search and groups

Select on the map

With the Select tool active, which is the default:

  • Click an object to select it.
  • Drag a box to select everything inside it.
  • Ctrl+click adds or removes an object.
  • Shift+click lets you choose between overlapping objects.

The status bar shows how many objects are selected, with their total area and length.

Search

Operation ▸ Selection ▸ Search (Ctrl+F) finds objects by ID, part of an ID or tag, optionally for one object type. Click a result to zoom to it, or click Select All Results to select every match.

Groups

Groups are named sets of objects, for example Phase 1 upgrades or Pump station catchment A. They are stored in the [GROUPS] section of the .inp file, in the same format Avaris DS uses.

  1. Select objects on the map and open Operation ▸ Selection ▸ Groups.
  2. Click Create Group… and enter a name.
  3. Later, double-click a group to select it and zoom to it. Use Add Selection and Remove Selection to change its members, or Rename… and Delete to change the group itself.

Bookmarks

Create Bookmark saves the current map view under a name. Manage Bookmarks lists them with Go To, Rename and Delete.

Add and remove objects

  1. Click Operation ▸ Edit ▸ Add.
  2. Click the layer to add to in the Layer View: Junctions, Outfalls, Storages, Dividers, Conduits, Pumps, Orifices, Weirs, Outlets, Subcatchments, Rain Gages or Map Labels.
  3. Click on the map:
    • Nodes and rain gages: one click per object.
    • Links: click the upstream node, optionally click to place bends, then click the downstream node.
    • Subcatchments: click the corners of the outline and double-click (or press Enter) to finish. Backspace removes the last corner.
  4. Press Esc to stop adding.

New objects get the next free ID and the default values set in Simulation ▸ Options ▸ Object Defaults. Conduit length is taken from the map when Auto length from map is ticked.

To delete objects, select them and click Remove or press Del. Links connected to a deleted node are deleted too.

Copy and paste

Ctrl+C copies the selected objects together with everything they use: inflows, RDII, groundwater, LID usage, curves, time series and patterns. Ctrl+V pastes them into the same model or into another model, even in another Avaris2 CS window. IDs that already exist are renamed with a suffix (_1, _2 …).

Edit geometry, split and merge

Edit Geometry

Turn on Operation ▸ Edit ▸ Edit Geometry; the status bar then shows Edit: ON. In this mode you can:

  • drag selected nodes;
  • drag link vertices;
  • double-click a link to add a vertex.

Turn the mode off to avoid moving objects by accident.

Split

Use Split to:

  • insert a new junction into a conduit at the point you click. The two new conduits keep the original properties, and the length is shared in proportion to the split point.
  • cut a selected subcatchment in two along a line you draw. Area and width are shared out by area.

Merge

  • Subcatchments: select adjacent subcatchments, click Merge and choose the one to keep. Areas, widths and curb lengths are summed. Percent impervious, slope, roughness and storage are area-weighted.
  • Conduits: select the junction where two conduits meet and click Merge to join them into one conduit.

Assign Outlet

Click Assign Outlet, click a subcatchment (Ctrl+click for several), then click the node it drains to. For many subcatchments at once, use Batch Assign Outlet.

Convert Type and Reverse

Convert Type changes selected objects into another type, for example a junction into a storage unit or a conduit into a weir, For nodes, the invert elevation and depth are kept and the other properties get default values. For links, the cross section and offsets are kept where the new type uses them. Reverse swaps the start and end nodes of the selected links, together with their offsets.

Edit properties

Edit values in the Properties pane or in an attribute table.

Several objects at once

  • Select the objects. In the Properties pane, choose the object type, then type a value: it is applied to every selected object of that type.
  • Click Batch Edit… to apply a value or an expression, such as x*1.1 to raise every value by 10 %.
  • In an attribute table, right-click a column header and choose Field Calculator… to calculate a field from other fields, for example elev + maxDepth.

Cross sections

For a conduit, click the pencil button next to Shape to open the Cross Section Editor. Pick the shape from the picture gallery, then enter its dimensions. The editor offers all the standard shapes, plus irregular (transect), custom (shape curve) and street sections.

Inflows and other per-object data

The pencil buttons in the Properties pane open the editors for:

  • Direct Inflows (time series and baseline with patterns);
  • Dry Weather Flows (average value with monthly, daily and hourly patterns);
  • RDII (unit hydrograph and sewershed area);
  • Groundwater;
  • LID Usage of a subcatchment.

Undo and redo

Every change, including bulk changes, can be undone with Ctrl+Z and redone with Ctrl+Y, or with the arrows in the quick-access toolbar.

The properties of every object type are explained field by field on these pages:

Edit GIS layers

Imported vector layers – buildings, boundaries, cut-off lines, mesh zones and any other shapefile, GeoJSON, KML or geodatabase layer – can be edited directly in Avaris2 CS, as in Avaris DS. The usual tools (Select, Properties, Remove, Add, Edit Geometry) then work on the features of that layer instead of the network.

Start and stop editing

  1. In the Layer View, right-click the layer and choose Start Editing. A ✎ appears in front of the layer name. Only one layer is edited at a time.
  2. Edit the features (below). Every change is one undo step (Ctrl+Z). A * after the layer name shows that there are unsaved edits.
  3. Right-click the layer ▸ Save Edits. Shapefiles are written back in place – only the .dbf when no geometry changed, the geometry in the layer's own coordinate system. Geodatabase, GeoJSON and KML layers are saved as a new shapefile.
  4. Right-click ▸ Stop Editing. If there are unsaved edits you are asked whether to save them. Removing the layer, opening another model and Create Meshes also ask before unsaved edits are lost.

Change log and history

Avaris2 CS records every change to a model: who made it, when, which object and variable, the old value and the new value. The record is kept in Model.osemhist.json next to the model.

Log of the selected object

The Log below the Properties pane lists the changes of the selected object. Changes that are not saved yet are shown in italics. Click a property name in the Properties pane to show only the changes of that variable.

Model Change History

Operation ▸ Change Log ▸ History, or Full Change History… in the Log window (Operation ▸ Change Log ▸ Log Window), lists every change in the model. You can:

  • filter it by user, object type, object, variable or value;
  • show only the changes of the selected objects;
  • export the list as CSV.

Click a row to select that object on the map.

In Project ▸ Settings ▸ Default you can choose:

  • whether a comment is requested each time you save;
  • how often edits are recorded: every second, every minute, every 10 minutes, or only the last value when the model is saved.
